# Password Generator

A desktop application built with WPF that generates secure passwords based on user-defined rules. The project follows the MVVM (Model–View–ViewModel) architectural pattern and focuses on clean separation of UI and business logic.

## Tech Stack

- .NET (WPF)
- C#
- MVVM pattern
- XAML
- ICommand / RelayCommand
- Data Binding

## Features

- Generate secure random passwords
- Configurable password length
- Option to include:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Real-time password preview
- Input validation and rule enforcement
- MVVM-based architecture (no code-behind business logic)

## 🚀 Running the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/Tymqek22/PasswordGenerator.git
   cd PasswordGenerator
   ```
2. **Open the solution file**
   ```bash
   PasswordGenerator.sln
   ```
3. **Build and run using Visual Studio**
